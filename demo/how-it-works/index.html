How this demo works

Build a change to the app beside the workboard. You review the plan and decide whether to keep the result.

  1. Describe

    Add a table column, build an interaction, redesign a screen, or change app behavior. Try: “Let’s add a date in table.”

  2. Review and run

    Choose Create plan, review it, then Approve plan & run. The agents build and check the result. Compare Candidate with Accepted.

  3. Accept

    Choose Accept change after the checks pass. Until then, the accepted app stays as it was.

Choose a mode

Guided
A scripted date-column tour with real browser checks. No model download.
Live
Choose Load Gemma to run on your device. The first download is about 3 GB; use a compatible desktop browser.
Recorded
Review your last successful Live run saved in this browser.

The team edits the full HTML, CSS and JavaScript. Accepted changes stay in this browser; the demo does not publish a website or make real payments.
